PROMPT — CORRECTION UNIQUEMENT DE LA PAGE D’INSCRIPTION BIZ-TRANSPAY

Je veux modifier uniquement la PAGE D’INSCRIPTION de Biz-transPay.

IMPORTANT :
Ne modifie pas la page d’accueil.
Ne modifie aucune autre page.
Ne touche pas aux fonctionnalités existantes, aux paiements, aux API, à la base de données ou à l’authentification, sauf adaptation technique strictement nécessaire pour appliquer cette modification.

1. SUPPRIMER « TYPE DE COMPTE »

Actuellement, le formulaire d’inscription contient :

« Type de compte »

avec :
- Compte personnel
- Compte marchand

Supprime complètement cette partie du formulaire.

L’utilisateur ne doit plus avoir à choisir entre « Compte personnel » et « Compte marchand ».

Il ne doit rester aucun :
- bouton ;
- menu ;
- carte ;
- option ;
- texte de sélection

concernant le type de compte.

2. CRÉATION AUTOMATIQUE EN COMPTE MARCHAND

Lorsqu’un utilisateur termine son inscription, son compte doit être créé automatiquement comme :

« Compte marchand »

L’utilisateur ne fait aucune sélection.

Dès la création du compte, il doit avoir accès à toutes les fonctionnalités actuellement disponibles pour un compte marchand.

Utilise le système de compte marchand déjà présent dans l’application. Ne crée pas un nouveau système de rôles.

Si le système possède déjà un champ permettant de déterminer le type de compte, attribuer automatiquement la valeur « marchand » lors de l’inscription.

3. CONSERVER LES AUTRES CHAMPS

Conserver tous les autres champs actuellement présents sur la page d’inscription, notamment :

- Nom complet
- Nom d’utilisateur
- Pays
- Numéro de téléphone
- Adresse e-mail
- Mot de passe
- Confirmation du mot de passe
- CAPTCHA
- Acceptation des conditions

Ne supprimer aucun de ces champs.

La seule partie à supprimer est le choix « Type de compte / Compte personnel / Compte marchand ».

4. MODIFICATION DU LIBELLÉ « NOM COMPLET »

Sur le formulaire d’inscription, le libellé :

« Nom complet »

doit être CENTRÉ horizontalement au-dessus de son champ de saisie.

Actuellement, il est positionné au début/gauche du champ.

Je veux qu’il soit visuellement centré.

Exemple :

              Nom complet
        ┌────────────────────┐
        │ Entrez votre nom   │
        └────────────────────┘

Le champ de saisie doit rester exactement fonctionnel.

Ne supprime pas le label HTML et ne casse pas son association avec le champ.
