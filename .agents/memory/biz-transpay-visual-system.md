Use **Kripa Regular** from the local frontend font assets as the single typeface for Biz-transPay. Preserve the existing Biz-transPay blue palette, shared card treatment, spacing, buttons, and responsive patterns for future changes. Use Diokoma (https://www.diokoma.com/) as the structural reference for card placement, proportions, whitespace, rounded forms, and overall page composition; do not copy its branding, colors, or content.

**Why:** The user explicitly selected Kripa as the preferred official typeface and chose Diokoma as the new visual reference for layout and card design while keeping Biz-transPay’s own identity.

**How to apply:** Reuse the shared CSS utilities and existing component patterns; do not add external font providers or introduce a separate visual language.
